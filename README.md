# Bunni POS

نظام كاشير لمقهى BNY يعمل من المتصفح (آيباد) — ملفات ثابتة بدون خادم.

- `menu.js` — الأصناف والأسعار
- `img/` — صور الأصناف (استبدل الملف بنفس الاسم لتغيير الصورة)
- الطلبات والإعدادات تُحفظ محلياً على الجهاز (localStorage)
- الطباعة: AirPrint أو Epson ePOS-Print عبر الشبكة (من تبويب الإعدادات)

للتشغيل محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.
