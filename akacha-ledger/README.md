# akacha-ledger — بوت مصاريف أكاتشا

بوت تيليجرام خاص لك ولشريكك: تسجّلون كل سحب من الدخل مع سببه، والبوت يفرزه
(حلويات / مستلزمات) ويعطيكم تقرير يومي وشهري. الدخل اليومي ينسحب تلقائياً من الكاشير
عن طريق موقع **akacha-pulse**. هذا البوت **مستقل**: ما يلمس الكاشير ولا البوت الحالي على جهاز المحل.

## الاستخدام في تيليجرام

| تكتب | النتيجة |
|---|---|
| `سحب 350 غيمة` | حلويات ← حلا غيمة، 350 ر.س |
| `200 مدريد بيكان` | حلويات ← تشيز مدريد بيكان (كلمة «سحب» اختيارية) |
| `سحب 120 بلاستيك أكواب` | مستلزمات، والوصف «بلاستيك أكواب» |
| `سحب 1500 كراسي` | مستلزمات |
| `اليوم` أو `/today` | دخل اليوم، السحوبات، الصافي، التفاصيل |
| `الشهر` أو `/month` | مجموع الشهر حسب الفئة، أكثر المستلزمات، ومن سحب كم |
| `الشهر 2026-10` | شهر معيّن |
| `دخل 10000` | يسجّل دخل اليوم يدوياً (يغلب الرقم التلقائي) |

بعد كل سحب يطلع زر **↩️ تراجع** لو انكتب غلط. الأرقام العربية (٣٥٠) تشتغل.

الحلويات وكلماتها في `lib/categories.js`. أي شي ما فيه اسم حلى ينسجل **مستلزمات**.

## التركيب (مرة وحدة، على الماك)

**1. سوّ بوت جديد:** في تيليجرام افتح **@BotFather** واكتب `/newbot`، واحفظ التوكن عندك (لا ترسله لأحد).

**2. انشر المشروع على Vercel:**
```bash
cd akacha-ledger
npm install
npx vercel link --scope i9a6is-projects      # اختر: مشروع جديد باسم akacha-ledger
```
بعدها من لوحة Vercel: المشروع ← **Storage** ← **Create** ← **Blob**، واربطه بالمشروع
(هذا يضيف `BLOB_READ_WRITE_TOKEN` لحاله).

**3. أضف المتغيرات** (Settings ← Environment Variables، اختر **Sensitive**، بيئة Production):

| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | التوكن من BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | كلمة عشوائية طويلة (أي حروف وأرقام، مثلاً ناتج `openssl rand -hex 24`) |
| `ALLOWED_USER_IDS` | رقمك ورقم شريكك مفصولين بفاصلة (شوف الخطوة 5) |
| `PULSE_URL` | `https://akacha-pulse.vercel.app` |
| `PULSE_DASH_KEY` | نفس قيمة `DASH_KEY` في مشروع akacha-pulse |

**4. انشر واربط تيليجرام:**
```bash
npx vercel --prod
TELEGRAM_BOT_TOKEN='...' TELEGRAM_WEBHOOK_SECRET='...' npm run set-webhook -- https://akacha-ledger.vercel.app
```

**5. اعرف أرقامكم:** كل واحد يرسل أي رسالة للبوت، يرد عليه «هذا البوت خاص. رقمك: 123…».
حط الرقمين في `ALLOWED_USER_IDS` وأعد `npx vercel --prod`. بعدها البوت يشتغل لكم انتم الاثنين بس.

**6. جرّب:** أرسل `اليوم`. إذا الدخل طلع «غير متوفر» شوف الفقرة الجاية.

## الدخل التلقائي — لازم يتأكد

الكود يقرأ `GET /api/data` من akacha-pulse (آخر ملخص أرسله الكاشير)، ويدوّر في `daily`
على صف تاريخه اليوم، ويأخذ أول حقل رقمي من: `net, netSales, total, sales, revenue, gross, amount`.
**ما شفت شكل الملخص الحقيقي** (مخزن في Blob وما سحبت مفاتيحه). إذا ما طلع الدخل:
عدّل `INCOME_KEYS` / `DATE_KEYS` في `lib/income.js` حسب أسماء الحقول، أو استخدم `دخل 10000`.

## التخزين والخصوصية

- كل سحب ملف JSON في Vercel Blob: `ledger/<الشهر>/<اليوم>_<معرّف عشوائي>.json`.
- ملفات Blob في هذا الإصدار **public** بروابط عشوائية ما تنخمّن (نفس طريقة akacha-pulse).
  الروابط ما تنعرض لأحد، بس لو تبغونها مقفلة تماماً ننقلها لقاعدة بيانات.
- البوت يرفض أي طلب ما فيه `TELEGRAM_WEBHOOK_SECRET`، وأي شخص مو في `ALLOWED_USER_IDS`.
